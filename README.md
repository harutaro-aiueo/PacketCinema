# Packet Atlas

SSH接続の開始から終了までを、パケットの往復と解説で追うWeb教材です。トップページを挟まずSSHを表示します。

## 起動

```sh
npm ci
npm run dev
```

表示されたローカルURLを開いてください。SSHは `#/ssh`、TCP単独の接続例は `#/tcp` でも直接開けます。

## SSHの流れと操作

`ssh learner@server` → TCP接続 → 鍵交換 → 公開鍵認証 → 対話シェル → `whoami` → 結果 → `exit` → SSH・TCP切断。

- 固定したクライアントとサーバーの間を、一つずつメッセージが移動します。
- 解説は通信図の中に表示し、通信シーンと端末内の処理でウィンドウの位置・大きさを揃えます。
- パケットは約5秒かけて滑らかに移動し、移動中も解説を表示します。通信図をクリックするとその位置で一時停止し、再クリックで再開します。Spaceでも停止・再開できます。
- 各シーンを約6秒で自動的に切り替え、最後まで連続再生します。通信は約5秒で移動し、到着を表示してから次へ進みます。端末内の操作も自動で進みます。「次へ」で先送りもできます。
- 「最初から」「戻る」「もう一度」「次へ」「最後へ」と段階ボタンで見直せます。
- 操作部以外にフォーカスがあるとき、左右キーで移動、Spaceで移動中の停止・再開、到着後も停止・再開できます。
- 常にアニメーションを表示します。画面クリック・Spaceで一時停止できます。
- `#/ssh?step=12` のようなURLで表示位置を共有できます（0始まり）。

## 構成

- `src/app/`: 教材の公開登録、URL解決、画面の組み立て
- `src/domain/lesson/`: プロトコル・シナリオ・ステップの型と検証
- `src/protocols/`: SSH/TCPの教材と再利用する通信部品
- `src/player/`: 共通の再生処理と操作・詳細表示
- `src/visualization/`: ノード配置と通信・端末内の演出
- `src/styles/`: 共通テーマとスタイルの読み込み
- `tests/contracts/`、`tests/e2e/`: 教材・依存境界の検証とブラウザ回帰

詳しくは[設計と依存ルール](docs/architecture.md)、[プロトコル追加手順](docs/adding-protocol.md)を参照してください。

## 表示モデル

実際のSSH接続・パケット取得は行いません。公開鍵認証に成功する代表例です。SSHは論理メッセージ単位で、TCPセグメントとの一対一対応ではありません。TCP接続と切断の制御情報は独立したステップで示します。

対話シェルのPTY要求とshell要求を表示します。入力文字はコマンドごとにまとめ、端末のエコー・プロンプト・端末設定の詳細は省略します。終了コードは対話シェルの終了を示します。切断はクライアントがSSH切断を通知し、TCPのFINとACKを別々に交換する一例です。最後にTIME-WAITの経過を説明します。

拡張交渉、認証方式探索、再鍵交換、再送、ウィンドウ調整、失敗系は省略します。鍵交換・認証・終了通知などの順序は実装により異なります。初回ホスト鍵確認は信頼できる別経路の指紋と照合するモデルです。鍵交換用、ホスト認証用、ユーザー認証用の鍵は区別します。

参照: [SSH transport / RFC 4253](https://www.rfc-editor.org/rfc/rfc4253)、[SSH authentication / RFC 4252](https://www.rfc-editor.org/rfc/rfc4252)、[SSH connection / RFC 4254](https://www.rfc-editor.org/rfc/rfc4254)、[TCP / RFC 9293](https://www.rfc-editor.org/rfc/rfc9293)。画面の詳細欄から各ステップの出典も開けます。

## 画面構成

画面の高さに合わせた1画面のキャンバスです。PCでは左右、スマートフォン縦画面では上下に通信します。図内の解説は要点を表示し、「詳しい解説」で全文と技術情報を開けます。詳細表示中は時間が止まり、閉じると元の再生状態に戻ります。詳細ウィンドウ内は必要に応じてスクロールできます。

最初の「SSH接続開始」は端末の入力演出です。約2秒でコマンドを入力し、Enterを示した後、約3.2秒でTCP接続へ進みます。入力演出もクリックで一時停止できます。

ページ下部の「フロー全体」は初期状態で閉じています。開くと全ステップ・通信方向・現在位置を表示し、項目を選ぶと該当場面へ移動して一時停止します。開いている間はページを下へスクロールできます。

SSH開始・whoami入力・exit入力・ホスト鍵確認・端末への復帰は、端末内の演出を約3.2秒で表示します。入力文字、確認段階、進行バーは同じ再生時間に同期し、一時停止時にすべて止まります。確認バーは処理順を伝える教材上の演出で、実測した処理時間ではありません。解説ウィンドウの位置と大きさは通信シーンと共通です。

プロトコルはヘッダーの「教材を探す」から切り替えます。名前・用途で検索でき、選択中は再生が止まります。Escapeまたは「閉じる」で元の再生状態に戻ります。
