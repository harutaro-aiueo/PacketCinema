# PacketCinema 教材追加

このスキルはPacketCinemaリポジトリ専用。以下のコードパスはリポジトリルート基準。

## 前提と実装

1. [プロトコル追加手順](../../../docs/adding-protocol.md)を読み、モデルは`src/domain/lesson/index.ts`、最小例は`tests/fixtures/example.ts`で確認する。共通層を変更する場合は[設計文書](../../../docs/architecture.md)も読む。
2. 扱うバージョン、登場機器、開始・終了条件、正常系・失敗系の範囲を定める。依頼と既存教材から判断できる事項は進め、教材の意味を左右する不明点だけ確認する。
3. RFC・標準・ベンダー公式資料を確認し、通信順序と成立条件を整理する。ステップの出典はその説明を裏付ける節へ対応付ける。既存の出典を無条件に引き継がない。
4. 追加手順に従って教材・再利用部品・公開登録を実装する。既存レイアウトで表現できる場合は共通層を拡張しない。新しい表現が必要なら教材名に依存しない機能として追加する。

## 完了条件

- 要求と応答の条件、方向、状態遷移、説明が整合している。簡略化や時間短縮は教材の注意事項で説明する。
- プロトコル固有の順序・条件を検証するテストを追加する。既存の型・契約テストが保証する構造を重複してテストしない。
- `npm test`、`npm run build`、`npm run test:e2e`を実行する。
- 新教材の表示は[レビュー用スキル](../packetcinema-review/SKILL.md)の「画面・再生」を参照して確認する。全教材の技術レビューに範囲を広げない。
- 教材追加に伴うREADME・設計・追加手順の変更は実際に変わった事項だけ反映する。
- 報告は追加内容、確認結果、制約、ローカルで開く教材URLを短くまとめる。アプリへの登録とPagesへのデプロイを区別する。
